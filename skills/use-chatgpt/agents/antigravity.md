# Google Antigravity & Gemini CLI Agent Adapter

Profile and runtime rules for Antigravity App, Gemini CLI, and Google DeepMind agent workflows.

---

## 1. Compound Engineering Loop (80/20)
- 80% planning & review via `ce-brainstorm` / `ce-plan` / `ce-code-review` / `ce-compound`.
- 20% execution via `ce-work` / `ce-simplify-code` / `lfg`.
- Root-cause debugging via `ce-debug` / `hunt`.
- Fable Circuit Breaker: Halt speculative edits if `failure_streak >= 2`.

---

## 2. Antigravity Skill & Subagent Synergy
- Map `@Superpowers` $\rightarrow$ `superpowers` skills (`systematic-debugging`, `test-driven-development`).
- Map `@get-fable` $\rightarrow$ `get-fable` skill pack (`fable-plan`, `fable-verify`, `fable-review`).
- Map `@Impeccable` $\rightarrow$ `impeccable` / `ui-ux-pro-max` design skills.
- Map `@CodeRabbit` $\rightarrow$ `code-reviewer` / `team-reviewer` subagents.

---

## 3. Durable Codification
- When an engineering mission concludes, codify new failure lessons, architectural decisions, and verified solutions directly to `docs/solutions/`.
