# Deliberation Contract

## Purpose

Deliberation exists to reduce framing error before GTD commits effort to planning or execution.

It must not become ritualized overthinking.

## Phases

### 1. Contemplate

Identify:

- desired outcome versus proposed solution
- hidden assumptions
- missing objective or success definition
- contradictions
- incentives and stakeholder tensions
- second-order effects
- alternative interpretations
- what would need to be true for the proposed direction to work
- what evidence could falsify the current framing

Output hypotheses worth testing, not conclusions disguised as insight.

### 2. Freshness search

Run the Freshness Gate before trusting external or versioned knowledge.

Use the runtime's current date in the search scope and record the search evidence in the Problem Model.

### 3. Research

Collect evidence relevant to the hypotheses.

Prefer current, direct, authoritative, and decision-relevant evidence.

Classify evidence as:

- supports
- contradicts
- weakly informs
- unresolved

Do not use source volume as a substitute for relevance.

### 4. Challenge

Actively try to prove the current framing wrong.

Ask:

- Is the proposed solution actually tied to the observed problem
- Could the symptom have a different cause
- Is there a simpler explanation
- Is there a no-build or no-change option
- Are we treating correlation, preference, or convention as evidence
- What failure mode would make this plan look obviously misguided in hindsight

### 5. Reframe

Construct the strongest evidence-backed problem statement.

A valid reframe may preserve the original framing, narrow it, broaden it, replace the proposed cause, reject the proposed solution, or reveal that the main need is a test rather than implementation.

### 6. Active ideation

Generate meaningfully different directions.

At least one candidate should test simplification or non-action when plausible.

Do not generate cosmetic variants of the same idea and call them alternatives.

### 7. Critique and synthesis

For each serious candidate, inspect:

- evidence fit
- expected value
- reversibility
- cost
- dependencies
- risks
- second-order effects
- verification path
- opportunity cost

Combine compatible strengths when useful.

### 8. Converge

Produce:

- recommended direction
- surviving alternatives
- rejected directions with reasons
- unresolved uncertainty
- decision that belongs to the user, if any

## Direction Gate

Use one status:

- `pending`
- `approved`
- `rejected`
- `provisional`

Approval is required before implementation planning when the decision is high-impact, preference-heavy, financially material, public, identity-sensitive, safety-sensitive, or hard to reverse.

A provisional direction may proceed to a reversible test when evidence gathering through action is cheaper than further analysis.

## Contemplation Sufficiency Gate

Stop deliberating when all are true:

1. desired outcome is understandable
2. major assumptions are visible
3. current-date freshness search is complete or its limitation is explicit
4. material contradictions have been investigated
5. at least one plausible alternative framing was considered
6. available evidence is sufficient for the current decision
7. remaining uncertainty is explicit
8. another thinking cycle has lower expected value than acting, testing, or asking for a Decision

If these are not true, continue only the phase needed to close the material gap.

## Anti-patterns

- analysis theater
- endless research
- contrarianism for style
- telling the user they are wrong without evidence
- brainstorming before problem framing
- recommendation by confidence language alone
- hiding uncertainty
- manufacturing false consensus between logical roles
- using approval as ceremony when no user Decision is required
- claiming freshness without current search evidence
