# GTD Output Profiles

Choose the output shape that matches task weight and what was requested.

## Small task

Clarified outcome, relevant assumptions, and the single next executable action. Skip the full brief if the work can resolve in one cycle.

## Substantial task

Updated Execution Brief covering:
- current status and active blocker
- knowledge ledger snapshot (Facts, Assumptions, Decisions, Unknowns changed this cycle)
- deliverables with evidence
- next executable action

## Handoff

Preserve without duplication:
- desired outcome and current status
- scope boundaries (in / out)
- knowledge ledger: important Facts, Assumptions, Decisions, Unknowns
- artifact paths, URLs, or external IDs
- verification evidence collected and missing checks
- blockers and owners when known
- next executable action
- suggested domain or specialist skill when relevant

Reference existing artifacts instead of restating them.

## Inline update (mid-execution)

One concrete progress unit only:
- which blocker was resolved
- which artifact was created or changed
- current state and next action

No ceremony. No re-summarizing prior history.
