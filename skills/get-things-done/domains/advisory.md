# GTD Domain Pack: Advisory & Strategic Decisions
## Selection signals
Strategic crossroads, career forks, startup pivots, co-founder disputes, executive trade-offs, project crisis triage, analysis paralysis loops, second opinions on major commitments, or requests for direct honest feedback ("what would you do?", "give it to me straight", "consult dad").
Non-selection signal: Technical bug fixes, code syntax debugging, database query optimization, or routine document authoring tasks without strategic decision stakes.
## Domain vocabulary
Keep distinct: symptom vs root problem, stated question vs real question, Type 1 decision (irreversible) vs Type 2 decision (reversible), verified fact vs unvalidated assumption, load-bearing constraint vs assumed constraint, unhedged recommendation vs neutral options list, next physical action vs passive consideration.
## Diagnostic questions
Ask only when blocking: What is the specific decision in front of you right now? What would you do if the cited constraint was removed? What does your gut say and why are you not trusting it? What happens if you get this wrong vs what happens if you do nothing? If forced to choose in the next 10 minutes, which way do you lean?
## Extra brief fields
`real_question`, `reversibility_class`, `selected_framework`, `advisory_mode`, `load_bearing_assumptions`, `risk_mitigation`, `kill_criteria`
## Readiness additions
- root dilemma is separated from surface symptom
- decision reversibility is classified (Type 1 vs Type 2)
- critical constraints (cash runway, deadlines, legal commitments) are verified or explicitly recorded as assumptions
- unhedged recommendation with 2–3 reasons is delivered
- at least one physical, time-bounded next action is defined
## Workstream patterns
- decision consult: root framing -> reversibility & framework -> recommendation -> risk mitigation -> GTD next moves
- honest feedback: structural strengths -> fatal flaw isolation -> necessary changes -> go/no-go gate -> action bridge
- anti-loop break: call out loop -> isolate root blocker -> 10-minute forcing question -> permission grant -> 24-hour action
- crisis triage: emergency stop -> scope cut to core value -> stakeholder renegotiation -> hardened delivery sprint
## Review additions
Check whether advice took a definitive stance instead of hedging, whether unverified fears were separated from facts, whether risk mitigation exists for the recommended path, and whether ownership was transferred to the principal.
## Completion checks
A clear assessment delivered, core trade-off and framework explicit, asymmetric risk mitigated, 1–3 physical time-bounded next actions recorded in the brief or session, and user commitment confirmed.
## Common traps
Diplomatically vague advice that avoids taking a stand, feeding analysis paralysis with more research, treating reversible decisions as irreversible life crises, confusing sympathy with actionable advisory, and closing without a concrete next physical action.
