# v1.1 change notes

This release candidate strengthens the GTD core contract and documentation without changing the v1 Execution Brief version number

Highlights

- explicit open decisions in the Execution Brief schema
- deterministic `assess-brief` checks for structural Ready and Done gaps
- clearer work states, routing, question policy, review, and evidence rules
- failure-driven domain pack authoring with collision testing
- public docs for quickstart, architecture, Execution Briefs, domain packs, and evaluation
- product-first README with claims tied to repository behavior

The package version moves to `1.1.0`
